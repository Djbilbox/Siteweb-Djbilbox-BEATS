Look-ahead true-peak limiter with auto-release and EBU R128 LUFS meters.

HUMPIRE HARDCAP is a look-ahead limiter for the end of your master chain. Raise the input gain by up to 24 dB, set a ceiling from -6 to 0 dBTP, and the limiter catches peaks before they happen with a look-ahead of 1 to 5 ms.

True-peak detection interpolates between samples, auto-release adapts the release time to the material, and a loudness meter shows momentary, short-term and integrated LUFS with a target you set from -24 to -6 LUFS.

When your integrated loudness stays on the target for two seconds, the screen flashes LEVEL UP.

Key features

True-peak limiting — Cubic interpolation catches inter-sample peaks. Ceiling from -6 to 0 dBTP.

Look-ahead — 1 to 5 ms, reported to the host as latency.

Auto-release — Release adapts to the material, or set it from 10 to 500 ms.

LUFS meters — Momentary, short-term and integrated loudness (BS.1770 K-weighting).

Loudness target — -24 to -6 LUFS with a target marker.

Input gain — 0 to 24 dB.

Preset manager with A/B — Factory presets grouped by category, user presets saved by name, A/B compare, undo and redo.

Resizable interface — Scales from 50% to 200% with the proportions locked. Simple and Clean display modes.

FAQ

Which DAWs does it work in?

It is a VST3 effect on Windows and macOS, plus Audio Unit on macOS. It is designed for FL Studio and should load in any host that supports these formats.

Is the LUFS reading certified?

The meter follows the BS.1770 K-weighting method, but the integrated gating is an approximation. Use it as a guide and check final masters with your usual loudness tool.
