### VOODOO
- Titre : VOODOO — Mystic Synth VST3 — 8 physical/modal engines, 70 presets
- Type : Instrument synth
- Prix : à définir
- Formats : VST3, Standalone
- Version : 1.0.0
- Court : Mystic synth with 8 physical-modeling engines (flute, sitar, oud, kalimba, erhu, choir) and 70 presets. VST3 / Standalone.
- Long : VOODOO is a mystic synthesizer built on physical and modal modeling, with no samples. Eight engines cover wind, plucked, bowed-style and vocal colours: Flute, Pan Flute, Shakuhachi (breath noise plus waveguide), Sitar, Oud (Karplus-Strong with jawari buzz and sympathetic strings), Kalimba (inharmonic modes), Erhu and Voodoo Choir (saws with formants). Five timbre controls reshape each engine (breath/vowel, body/resonance, brightness, width/detune, texture). The LFO routes to pitch, filter, amplitude or timbre; the effects section adds reverb, chorus, distortion and a ping-pong delay. 12 voices, mono/poly, glide, pitch-bend and mod wheels (CC1). 70 factory presets in 7 banks of 10; user presets save as .voodoopreset. Resizable interface. VST3 and standalone.
- Features : 8 physical/modal engines, no samples; 12 voices, mono/poly, glide; 5 timbre controls per engine; LFO to pitch/filter/amp/timbre; Reverb, chorus, distortion, ping-pong delay; 70 factory presets, user presets (.voodoopreset); Resizable GUI (500-2000 px wide)
- Requis : Windows 64-bit; VST3-compatible host (e.g. FL Studio) or standalone application. No sample library to install (synthesis only).

- Type : Instrument synth
- Prix : à définir
- Formats : VST3, Standalone
- Version : 1.0.0
- Court : 808 and bass synth with unison, filter envelope, mono legato and 70 presets. VST3 / Standalone.
- Long : WARZONE808 is an 808 and bass synthesizer for trap, hip-hop and bass music. The EXPANSION cassette loads additional .wz808exp packs. User presets save as .wz808preset. Resizable interface. VST3 and standalone.
- Features : PolyBLEP oscillators, TPT filter; Unison up to 7 voices with detune; Filter envelope (depth, A/D/S) and velocity; Mono legato with note-stack fallback; 16 voices, +/-12 semitone pitch; 70 presets incl. Expansion Vol.1; .wz808exp expansion loader; Resizable GUI
- Requis : Windows 64-bit; VST3-compatible host (e.g. FL Studio) or standalone application. No sample library to install (synthesis only).

### OCCITANIE
- Titre : OCCITANIE — Occitan Instruments Synth VST3 — 8 engines, drone, 70 presets
- Type : Instrument synth
- Prix : à définir
- Formats : VST3, Standalone
- Version : 1.0.0
- Court : Synth of Occitan folk instruments: cabrette, vielle, galoubet, accordion, with drone. 70 presets. VST3 / Standalone.
- Long : OCCITANIE is a synthesizer of Occitan and European folk instruments, built without samples. Eight engines: Cabrette (nasal reed with breath), Vielle (bowed strings with buzz), Galoubet (recorder flute), Mandoline (Karplus-Strong with tremolo), Guitare, Accordéon (three reeds with musette detune), Choir and Carillon (inharmonic modes). A DRONE layer an octave below can be added to any engine for bagpipe or hurdy-gurdy textures. Filter (LP/HP/BP), ADSR, reed/body/bright/drone/velocity controls, width and texture, LFO, glide, mono/poly, reverb, chorus, distortion and delay. 16 voices. 70 presets in 7 banks of 10 with Occitan names (Capitole Cabrette, Canal du Midi, Montségur...). User presets save as .occpreset. VST3 and standalone.
- Features : 8 folk engines: cabrette, vielle, galoubet, mandoline, guitare, accordeon, choir, carillon; Drone layer on any engine; Reed/body/bright/drone/velocity controls; Filter LP/HP/BP, ADSR, LFO; 16 voices, mono/poly, glide; 70 presets, user presets (.occpreset); Reverb, chorus, distortion, delay
- Requis : Windows 64-bit; VST3-compatible host (e.g. FL Studio) or standalone application. No sample library to install (synthesis only).
