Six-band EQ with Mid/Side, minimum or linear phase and a real-time FFT analyzer.

HUMPIRE SKILLTREE is a six-band parametric equalizer drawn as a skill tree: each band is a node you drag on a CRT-style screen. Dragging moves the frequency and the gain, the mouse wheel changes Q and a double-click switches the node on or off.

Band 1 is a low shelf, band 6 is a high shelf and bands 2 to 5 are peaking filters, each with 20 Hz to 20 kHz frequency, plus or minus 18 dB gain and a Q from 0.2 to 10. A 24 dB per octave high-pass (20 Hz to 1 kHz) and low-pass (1 kHz to 20 kHz) frame the curve.

Switch the target to Mid or Side to equalize only the center or only the stereo width, and switch the phase mode to Linear for a phase-neutral FIR (declared latency: 2048 samples).

Key features

  • 6 interactive bands — Low shelf, four peaking bands and a high shelf: drag nodes, wheel for Q, double-click to bypass a band.
  • 24 dB/oct high-pass and low-pass — High-pass from 20 Hz to 1 kHz and low-pass from 1 kHz to 20 kHz.
  • Stereo, Mid or Side — Equalize the whole signal, only the center or only the sides.
  • Minimum or linear phase — Linear phase uses a 4096-tap FIR and reports 2048 samples of latency.
  • FFT analyzer — Real-time spectrum behind the curve, switchable.
  • Output trim — Plus or minus 18 dB of output gain.
  • Preset manager with A/B — Factory presets grouped by category, user presets saved by name, A/B compare, undo and redo.
  • Resizable interface — Scales from 50% to 200% with the proportions locked. Simple and Clean display modes.

FAQ

Which DAWs does it work in?
It is a VST3 effect on Windows and macOS, plus Audio Unit on macOS. It is designed for FL Studio and should load in any host that supports these formats.

Does linear phase add latency?
Yes. Linear phase mode reports 2048 samples of latency to your host. Minimum phase mode adds none.

Can I EQ only the stereo width?
Yes. Set the target button to Side to process only the side signal, or Mid for only the center.

Can I save my own presets?
Yes. The SAVE button stores the current settings under a name you choose, and they appear in the User category of the preset menu.
