Stutter, tape stop, filter sweep and reverse on two XY pads, with MIDI learn.

HUMPIRE COMBO turns four one-shot effects into a game controller: STUTTER, TAPE STOP, SWEEP and REVERSE are buttons you hold, and two XY pads set their parameters.

The left pad controls the stutter rate (X) and the filter (Y). The right pad controls the tape-stop time (X) and the reverse length (Y). Two triggers add drive and set the effect mix. Stutter and reverse lengths follow the host tempo.

The effects can also be triggered from MIDI notes 36 to 39 by default, and MIDI learn lets you map each effect to another note.

Key features

  • Stutter — Repeats a slice of the audio from 1/32 to 1 beat.
  • Tape stop — Slows the signal to a halt over 0.1 to 2 seconds.
  • Filter sweep — A resonant low-pass sweep from 18 kHz down to a target set by the left pad (40 Hz to 18 kHz).
  • Reverse — Plays the last 1/16 to 2 beats backwards.
  • Two XY pads — Stick-style pads with spring-back.
  • MIDI trigger and learn — Notes 36 to 39 by default, remappable.
  • Preset manager with A/B — Factory presets grouped by category, user presets saved by name, A/B compare, undo and redo.
  • Resizable interface — Scales from 50% to 200% with the proportions locked. Simple and Clean display modes.

FAQ

Which DAWs does it work in?
It is a VST3 effect on Windows and macOS, plus Audio Unit on macOS. It is designed for FL Studio and should load in any host that supports these formats.

How do I trigger it from MIDI?
Route a MIDI track or keyboard to the plugin. Notes 36 to 39 trigger the four effects. Use MIDI LEARN to remap them. The plugin needs a MIDI input, which depends on your host.

Can I save my own presets?
Yes. The SAVE button stores the current settings under a name you choose, and they appear in the User category of the preset menu.
